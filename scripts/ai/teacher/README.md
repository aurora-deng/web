# AI Teacher 预留边界

本目录只有设计说明，没有 teacher 客户端、自动调用、凭据配置或后台任务。
现有 Ollama / 远程推理 Provider 不等于已经接入训练数据 teacher。

如果以后增加 teacher：

1. 数据来源必须是明确授权的训练输入；默认优先合成样本，禁止读取生产会话、账号资料或真实凭据。
2. 模型 / Provider / 请求地址、依赖版本、协议、许可证、数据外发范围和资源预算需先明确并审批；不得从输入样本接受任意 URL。
3. 鉴权从预配置的机制引用；不得记录、回显或写入 Git。默认不继承当前进程全部环境。
4. 输入、输出、总记录数、长度、超时、重试、并发与成本必须有上限；未知结果不能无限重试。
5. 输出先落入隔离候选数据，保存来源、授权及生成参数摘要；经过校验和人工选择后，才允许交给训练链路。
6. 离线 fixture / mock 只证明接口行为，不证明 teacher 质量、模型收益或生产可用性。

本说明不授予联网、下载或发送本地数据的权限，也不会自动启用任何外部模型。
