# 考研周计划

1. 确认科目、目标、可投入时段和已经明确的截止时间。
2. 用户勾选参考研途时，使用 `study.read_progress` 取得今日安排、已完成、逾期和未来七天未完成数量。用这些数量调节计划负担。
3. 写出本周目标、每天最重要的任务、预计用时、完成标准和机动时间。资料不足时标明假设，避免杜撰日期或分数。
4. 给出可复制的计划文本。用户可编辑后带到研途。

示例。用户说「408 优先计网，工作日每天 2 小时」，先给前置知识、两次限时训练和一天复盘。积压较多时优先减少新增任务。
