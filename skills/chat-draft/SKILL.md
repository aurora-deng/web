# 聊天起草

1. 从输入确认要传达的信息、语气和希望对方采取的行动。需要补充事实时留出占位提示。
2. 返回一条可以直接编辑的消息正文。保持事实准确，避免擅自承诺。
3. 用户通过 `chat.list_conversations` 选择收件会话。用名称和会话类型协助核对，同名会话以实际标识绑定。
4. 将草稿带入原有聊天框。由用户检查收件人和正文后点击原页面的发送按钮。

示例。协调演示时间时，保留用户给出的候选时段，并请对方确认其中一个。
