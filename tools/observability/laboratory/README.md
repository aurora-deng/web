# 隔离实验编排

放置实验装配、双节点和网关隔离入口、场景生产、探针、测试告警接收、资源实验及预览。输入是显式运行目录、已供应的二进制、隔离配置和合成场景；输出是该运行目录中的测量记录及受管实验生命周期。

继续使用原命令，例如 `python -m tools.observability.lab --help`；模块导入不会启动服务。依赖版本与资源预算由原供应脚本和运行参数约束，本轮没有下载或升级。实际运行可能建立监听、写测试数据库或产生请求，必须另行确认隔离目标，不因目录迁移获得新授权。

不把进程身份检查中的原模块名改成新实现名；不连接正式库，不把实验工具打进正式运行包。
