## 二、单元测试 12 个用例索引

### BufferTest (1个)
- `AppendsCompactsAndFindsDelimiters` — 小容量触发压缩/扩容，验证数据不丢失 + CRLF/CRLFCRLF 查找

### HttpParserTest (7个)
- `WaitsForHalfPacketAndContentLengthBody` — TCP 半包 + Content-Length 正文
- `LeavesPipelinedRequestInBuffer` — HTTP 流水线，第二个请求留在 Buffer
- `DecodesChunkedBodyAcrossPackets` — 跨包 chunked 解码
- `ParsesByteRangesAndRejectsConflictingLengths` — Range 解析 + CL/TE 冲突拒绝
- `EnforcesRequestLineHeaderAndContentLengthLimits` — 三种长度限制
- `RejectsIncrementalChunkedBodyOverLimit` — 增量 chunked 累计上限
- `RejectsAmbiguousRequestFramingAndMissingHost` — 四种非法请求
- `RequiresResetAfterDeliveryAndParsesConnectionTokens` — reset 必要性 + Connection token

### ResponseSenderTest (1个)
- `SendsWithoutSubReactor` — socketpair 独立发送验证

### HttpRangeTest (2个)
- `ResolvesClosedOpenSuffixAndInvalidRanges` — 闭区间/开放/后缀/越界
- `PreservesContentRangeForMemoryAndFileBodies` — Content-Range 保留不覆盖

### RouterTest (3个)
- `MatchesDynamicRouteAndExtractsParameter` — /user/:id 参数提取
- `MiddlewareCanShortCircuitRoute` — 中间件不调 next 即短路
- `ProducesNotFoundResponse` — 404 完整响应

## 三、黑盒测试 10 个场景索引

1. **Keep-alive + 动态路由** — 同一连接请求 / 和 /user/123
2. **认证短路** — /admin 无 token 返回 401
3. **Chunked 流式** — /stream1 返回 chunked 编码
4. **畸形输入** — HTTP/9.9 + CL/TE 冲突 → 断开连接
5. **正文限制** — 2MB Content-Length → 断开
6. **Keep-alive 多请求** — 3 次连续请求
7. **10000 流水线** — 批量写入 10000 个请求
8. **Range 206 + ETag 304** — 静态文件条件请求
9. **1GB 稀疏文件** — 末尾 10 字节 sendfile
10. **Executor 异步** — /slow 期间 /fast 立即返回

## 四、关键命令

```bash
# 运行全部测试
bash scripts/run_tests.sh

# 手动配置+编译+测试
cmake -S . -B build-tests -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build-tests --parallel
ctest --test-dir build-tests --output-on-failure

# 只运行黑盒测试
python3 tests/integration/http_blackbox.py --server ./build-tests/webserver

# ASan + UBSan
bash scripts/run_tests.sh -DWEBSERVER_ENABLE_ASAN=ON -DWEBSERVER_ENABLE_UBSAN=ON

# TSan (独立目录)
BUILD_DIR=build-tsan bash scripts/run_tests.sh -DWEBSERVER_ENABLE_TSAN=ON

# 模糊测试
CC=clang CXX=clang++ cmake -S . -B build-fuzz \
  -DBUILD_TESTING=OFF -DWEBSERVER_BUILD_FUZZER=ON \
  -DWEBSERVER_ENABLE_ASAN=ON -DWEBSERVER_ENABLE_UBSAN=ON
cmake --build build-fuzz --target http_parser_fuzz --parallel
./build-fuzz/http_parser_fuzz fuzz-corpus -max_len=2097152
```

## 五、核心概念备忘

- **PARSE_NEED_MORE**: 解析器暂停信号，状态不 reset，等更多数据到达后继续
- **PARSE_ERROR**: 解析错误，当前框架策略是关闭连接（不发送 400/413）
- **HTTP 半包**: TCP 一次 recv 只读到部分请求，解析器必须支持增量解析
- **HTTP Pipelining**: 同一连接连续发送多个请求，解析器只消费当前请求的字节
- **请求走私**: CL+TE 同时出现导致前后端定界不一致，必须拒绝
- **慢速攻击**: 持续发送小段合法数据占用连接，需要累计长度限制
- **TSan 不能与 ASan/UBSan 混用**: 运行时库替换实现互不兼容
- **Fuzzer 的 PARSE_ERROR 不是崩溃**: 随机输入大部分非法，Sanitizer 报告才是判定标准
- **Fuzzer 防卡死**: 检查 parse() 返回 OK 但 readableBytes() 未变，主动退出
- **gtest_discover_tests**: 运行时发现 GoogleTest 用例并注册到 CTest
- **生成器表达式 $<TARGET_FILE:webserver>**: 构建时展开为可执行文件路径
