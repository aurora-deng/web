## 度（已经帮你卡好）

### 学到什么程度算够（收尾 + 转机器人）

1. 能说明 **单元 / 黑盒 / 压测 / fuzz** 各证明什么（不是会背工具名）。  
2. 能指出一个 **不变量** 并用现有用例对应（例：Worker 阻塞不得拖死同 Reactor 其他连接 → `/slow`+`/fast`）。  
3. 知道改 Runtime 边界后该回归哪几条。  
4. 知道 Sanitizer / 故障注入 **何时用**，不要求本仓建成故障平台。

### 明确不学（本阶段）

- 测试理论长课、覆盖率仪表盘产品化  
- 为抬 QPS 去研 HTTP/2、WebSocket  
- 替代收尾去「系统补测试框架」

### 建议学时（若你下令开始）

- **第一轮 1～2 小时**：对照 `unit_tests.cpp` + 黑盒场景表，只建立「不变量 ↔ 用例」表。  
- **第二轮可选**：自己口述 3 条新不变量（先不写代码）。  
- **写测试代码**：再等你第二道命令。
