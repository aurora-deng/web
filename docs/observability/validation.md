2026-11-21。日常 Linux Observer 的旧版本在 VM 回环接口读取 15 分钟、6 小时和 7 天总览，各 3 次中位数分别为 23.73 ms、56.89 ms 和 338.62 ms。该组数据用于定位慢段。

### 本轮联调发现并修复

- 原来默认 Explore 使用轻量档的解析路径，真实 Prometheus 的函数直方图无法正常下钻；现按数据源能力选择真实 `query` 或 `query_range`，瞬时向量/标量和范围矩阵统一投影。

- 原浏览器脚本把减法表达式误当无效 PromQL，现以真正不完整的语法验证查询报错与恢复。
- 发送完测试请求后立即断言全局执行中为零，会碰到 scope 析构和后台健康请求；改为五秒内等待可证明的静止样本，超时仍失败。
