# M7 可观测与数据闭环 · 从症状回到同一任务

P0 · S1 定事件，S2 打通链路，P1 · S3 做 ROS 回放。Observer 面向任务与证据查询，原始高频数据由专用录制管理。

## 技术要求

| 数据 | 保存方式和使用方式 |
|---|---|
| 指标 | 队列、水位、命令应用 ACK、重连、拒绝、录制丢弃；使用有限维度，画出分位和变化趋势 |
| Trace 与事件 | gRPC、调度、执行与回报保留关联 ID；稀有的安全、超时和恢复事件可按工单重放 |
| 原始记录 | 本地 rosbag2/MCAP，保存版本、时间段、checksum、可读索引和权限；按记录 ID 引用到 Observer |
| 数据治理 | 明确保留期、容量、访问源、持久化失败和导出权限；使用合成样本代表测试流量 |

## 已有基础与待补能力

- **已有**。Observer 已处理指标、Trace、结构化日志和资源视图。 `device.window`、`device.command`、`device.safety`、`device.recording` 及 DAG 事件已有契约和样例。历史 19.51% 是某轮 A/A 的噪声量级，不能直接套用到车队。[设备事件契约](../../../tools/observability/observer/events.py) · [历史测量](../../observability/validation.md)
- **本轮**。C++ 边缘、Agent 审批和 90 秒合成设备回放可通过独立 Observer API 按 Trace 查询。测试覆盖事件重复导入、低质量样本、回放摘要、满配额整批回滚和观察端停止时的业务隔离。真实 ROS 记录接入和生产告警联动留在后续现场验收。 [隔离采集链路](../../ops/validation/m00-m07.md) · [记录和质量规则](../../../tools/agent/episode_recording.py)

## 实施步骤

1. 复用已有事件契约，为计划、部署和回放核对字段。ID 保留在 Trace/事件，跟踪指标按阶段、错误类和样本器聚合。
2. 对 M4 最小图和 M6 流添加低开销埋点。检查同一工单的派发、接受、开始、拒绝或结果，输出 Trace 与阶段耗时。
3. 让边缘统计序列和时钟质量，按窗口上报，明确重复、乱序、空洞和舍弃。采集拥塞时先保护业务与控制预算。
4. 接入一个真实 ROS 回放包，存原始文件和摘要。如果包含未授权媒体，使用自采安全样本或合成记录替代。录制完成后核对格式、摘要与关联区间。
5. 固定 90 秒片段复盘一个问题，生成失败清单和评测样本候选。默认监控沿用七天保留。入选证据按授权另存脱敏摘要、配置、时间段和原始记录引用，单列保留期限。训练使用前核对许可、时间质量和切分方式。[Observer 保留与清理](../../observability/architecture.md)

## 预期产出

一张车队任务 Trace、一份可按时间定位的失败报告、一个复放包、一次记录质量检查和一组同配置的 A/A 对照。G2 先证明端到端可查，G3 补 ROS 真实回放。

## 验收标准

| 检验 | 通过条件 |
|---|---|
| 事件链 | 从任务到边缘执行有完整 ID，失败能指到一个阶段和可重放的证据 |
| 丢弃与数据守恒 | 给固定样本注入重复、乱序和缺失，记录中的进入、接受、合并、舍弃与夹具逐项对得上 |
| 关联回放 | 相同录包重复两次，在固定配置与有效区间得到相同控制事件序列或已定义的状态等价结果 |
| 资源隔离 | 短时停采集或撑满预算，记录拒绝/丢弃，控制链路仍保有可验收的任务收束 |
| 性能报告 | 有样本数、负载、P50/P95/P99、时间基准和 A/A 波动。差异落在噪声区域时记录证据不足 |

自测。收到一个「机器人网络抖动」告警，如何从应用 ACK、节点执行和丢帧数据定位是通信还是本体慢。
