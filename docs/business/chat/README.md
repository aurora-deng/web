# 缘续聊天、群组与消息可靠性 · 业务说明

会话接口读取会话摘要、成员和偏好，HTTP 历史支持分页与搜索定位，WebSocket 承载发送、已读和实时通知。业务仓储在一个事务内保存消息、分配会话内序号并写入 Outbox，随后返回持久化 ACK。接收端实时推送、离线恢复和已读水位各有自己的状态。

| 概念 | 服务端如何处理 |
|---|---|
| 重试 | 同一发送者沿用客户端幂等键，读取同一条持久化结果 |
| 历史与未读 | 按会话序号、目标已读水位和访问权限查询 |
| 群治理与撤回 | 当前成员角色、归属和有效时间窗在服务端验证 |
| 免打扰 | 修改本人提醒偏好，历史和未读继续同步 |

公开服务先检查成员退出后的历史、撤回后的旧消息、ACK 丢失重试和双实例实时投递。测量时分别记录持久化 ACK 与接收端可见的延迟。
