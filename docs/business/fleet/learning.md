# gRPC 车队调度、边缘接收与对账 · 学习与复验

1. 用 [独立系统运行手册](../../ops/validation/cpp-systems.md) 启动回环协调器和模拟边缘。提交同一合成工单两次，比较 ID、接收 ACK 和最终结果，解释接收确认与动作完成的区别。
2. 按 M05 复跑回执中断和重启对账。尝试用旧派发代号回报，查日志和状态是否保持一致。
3. 跑 M06 慢客户端实验，记录订阅数、拒绝数和工单完成数。对比两条流有界运行时第三条被拒绝的可观测现象。
4. 学会阅读固定负载报告。对照样本和 P99 解释为什么零失败的 4,000 次 ACK 仍要继续优化延迟。
