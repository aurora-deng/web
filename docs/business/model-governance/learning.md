# 知识库、RAG、模型评测与训练 · 学习与复验

1. 在隔离站导入两个合成文本，每段放一个可辨认标记。问需要引用其中一篇的问题，记录引用编号；切换账号，用相同问题验证资料边界。
2. 发布两条测试动态，仅对其中一条启用训练授权。查看候选集，再撤销授权并重查。画出内容发布、候选筛选、样本版本和发布审批的顺序。
3. 复跑 M03 的合成数据训练评估。把训练和评测按会话拆分，保存对应摘要、各模型耗时与命中率。能解释为什么 13/24 对比 24/24 时要保留规则路径。
4. 观察一次模型注册、评测拒绝、晋级和回滚的审计，区分可加载、达到评测门槛和上线容量这三项事实。
