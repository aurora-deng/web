# 缘生广场、统一动态、榜单与内容治理 · 业务说明

统一动态共享正文、媒体和互动。发布频道决定出现于个人主页还是缘生广场。受权访问的树故事可以显示在 3D 场景与故事流，个人动态按作者选择的范围展示。好友申请入口需按发布者设置判断。

七日榜只统计符合树频道和有效状态的内容，用去重互动和时间计算热度。举报交给内容治理，作者删除和管理员隐藏按规则处理。运行时重点核对隐藏后的主页、列表、收藏、分享和媒体旧链接，以及榜单换位是否只创建预期公告。
