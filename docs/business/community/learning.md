# 缘生广场、统一动态、榜单与内容治理 · 学习与复验

1. 在隔离站用作者、好友、陌生人对比公开树故事、好友动态和仅自己可见动态。在每个入口记下返回的动态编号，检查“双频道”是同一份正文与互动。
2. 让同一用户给一个果实重复点赞和多次回复，再让另一用户回复。观察七日榜的计数和快照。解释为什么回复数量与参与人数可以不同。
3. 举报后用内容管理员处理隐藏。重查榜单、收藏、分享和旧媒体 URL。用普通用户试图删除他人内容，记录拒绝；再核对管理员处置的审计。
4. 在业务档运行 `ctest --test-dir "$WEB_BUILD" -R 'function3_tree_contract|function3_postgres_contract' --output-on-failure`。真实 PG 测试需使用已配置的隔离库。
