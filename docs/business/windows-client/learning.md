# Windows Companion 与私人资料 · 学习与复验

1. 从客户端的本机入口访问测试站点。记录浏览器请求的三个目标，分别是本机静态入口、代理的站点接口和本地助手接口。
2. 使用无敏感内容的 TXT 导入本地助手。打开好友式入口与侧栏检查知识资料可共同搜索；切换账号，检查目录和历史隔离。
3. 按客户端运行手册在隔离站验证 HTTPS、WebSocket 和 SSE，随后换成错误的测试证书验证连接拒绝。检查本机日志和 Linux 业务日志的内容范围。
4. 阅读 `LoopbackPolicy`，用一组同源和跨源请求解释允许与拒绝的理由，再核对代理目的地址是否由配置固定。
