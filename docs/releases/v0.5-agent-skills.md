# v0.5-agent-skills 发布说明

在 `v0.4-fleet` 的基础上保留 Fleet P0 可靠性改进，并给 NEBULA 的个人助手小研增加考研、聊天和广场技能。Fleet 可靠性测试沿用其独立的证据记录。 [代码对比](https://github.com/aurora-deng/web/compare/v0.4-fleet...v0.5-agent-skills) · [Fleet P0 可靠性验收](../ops/validation/fleet-p0-hardening.md)

| 变化 | 当前交付 |
|---|---|
| 学习 | 周计划和错题复盘支持编辑与复制，可选读取当前账号的四项研途计数 |
| 聊天与广场 | 会话和分类由本人选定。草稿进入原编辑器，发送与公开发布由本人在页面确认 |
| 工程 | 小研技能和只读工具有独立目录及四份 `SKILL.md`。源码 CI 加入账号工作区 HTTP 回归。贡献指引、问题反馈和 PR 模板记录复现版本与证据 |

## 2026-11-24 验收

| 验收范围 | 结果 |
|---|---|
| Windows 源码检查 | 111 项前端合约通过，含 5 项技能合约。51 项 Observer HTTP 用例通过 |
| 研途真实 HTTP | 2 项临时工作区用例通过，覆盖账号隔离、无效日期、四项统计口径以及本地来源数据排除 |
| Edge 新功能 | 通过网页发送范围确认、两项考研技能、聊天草稿会话绑定、广场公开确认、换号拒绝和 Windows 私人推理入口 |
| Edge 既有小研 | 历史压缩、偏好记忆、IndexedDB 重载恢复及账号隔离复验通过 |

Edge 使用真实页面与合成模型、业务请求替身。真实模型答题质量和站点推理连通性按部署环境另行验收。 [机器可读验收记录](../../artifacts/v0.5-agent-skills/verification.json)

## 启用与回退

本版为源码发布。用现有构建和运行入口更新前端资源，以及网关后面的研途账号服务。模型接入复用站点、用户或 Windows 私人模型设置。已有站点、账号、消息、研途资料和数据库迁移沿用现有部署。回退时用上一版前端快照并切回上一版研途账号服务。 [技能操作](../business/assistant/skills.md) · [研途启动与回退](../ops/runtime/nebula-yantu-community.md) · [构建复现](../ops/validation/reproduce.md)
