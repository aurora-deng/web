# Function3.1 · 开发快照

2026-11-06。基线为公开开发分支的 `925aa4c`。本分支保存可复现的源码、构建配置、文档与测试。线上曾分批部署验证，浏览器静态发布版本与整仓资源版本因发布范围不同而分别记录。本次整仓前端资源版本为 `144f1e6009a3d461`。

## 本版变化

- **账号与外观**：登录、注册、聊天、苦情树、个人主页及管理区沿用同一套水岸主题；深浅配色和移动端保留。背景、粒子与图像原生模块只复用一份。
- **聊天**：三分钟撤回窗口由后端判定；收到撤回 ACK 后，即使实时广播丢失，发送端也能更新。权限、幂等、历史状态仍由服务器校验。
- **语音**：保留本地 Kokoro，增加可选的设备中文音色；已有云 API Key 的用户可自选云语音。清理停用代理入口，修复公告切音色和试听取消时的旧请求回写。
- **工程**：追加 A/A 测量完整性检查、资源版本校验与前端回归；不涉及新数据库迁移或通信核心修改。CMake 预设属于构建配置，容器草案尚未验收。
