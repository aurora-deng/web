# WebSocket 架构演进课程

这里保存早期 2.0 的第 5–15 课。文件前缀统一使用 `lessonNN_`，与后续协议接入的 [`phase5.md`](../phase5.md) 区分。课程按下面的顺序阅读：

| 课次 | 主题 |
|---|---|
| 05–07 | 连接身份、根协程、帧与消息状态、UTF-8 和 Close |
| 08–09 | 背压、出站完成语义和公平性 |
| 10–13 | 应用投递、重试、接收端幂等、退避与指标 |
| 14–15 | Executor 线程边界、handler 取消与隔离 |

文件名按课次排列；每篇记录当时的设计决策。当前系统的最终行为以 [`ARCHITECTURE.md`](../ARCHITECTURE.md) 和项目 [README](../../../README.md) 为准。
