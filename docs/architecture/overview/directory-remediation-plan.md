# Function3.7 目录整改与验收清单

此清单固定当前收尾范围，避免发现一个目录就无限增加迁移。目录整理与性能改动分别验收；已提交不等于已部署。

## 已实施，待完整运行验收

| 范围 | 已落地 | 剩余验收 |
| --- | --- | --- |
| Agent | 18 个工具与 19 个技能独立声明、实现或配方及说明 | 保持原生目录生成物、权限和副作用边界 |
| AI | 推理、模型治理、RAG、训练和脚本职责拆分 | Linux 服务与 Worker 链接、运行验收 |
| 应用业务 | 66 项路径迁移，领域接口归回账号、联系人、聊天、文件、消息、学习等模块 | 最新完整构建和业务回归 |
| Observer | 29 个实现归入职责包 | 路径迁移链与运行包引用核验 |
| 监控工具 | 23 个实现归类，20 个稳定 CLI 保留 | 真实页面和网关链路验收 |
| 非 AI 运维 | 8 个脚本归入数据库、数据、运行和验证 | 隔离环境 shell 与生命周期验收，不操作正式库 |
| 应用观测 | 15 项文件按日志、指标、追踪等职责整理 | C++ 完整编译，不以语法检查代替链接 |
| CI 工作流 | 总入口与 5 条可复用验证链路，扩展目录与契约检查 | GitHub 平台实际执行尚未触发 |

迁移的历史摘要不重新计算。Git 会在 LF 与 CRLF 之间转换文本换行，测试仅接受这两种统一换行表示；混合换行、正文、空格、尾部换行或二进制变化不因此被忽略。该兼容规则只用于目录迁移测试，不用于模型、依赖或运行时安全校验。

| 编号 | 实际情况 | 后续处理 | 对应影响 |

| D2 | `tests/project/` 有多种项目级契约测试 | 已按被测职责建立 tests/project/README.md 导航；保留直接执行与辅助导入路径 | 直接执行入口、共享测试辅助模块、CI 清单和导入路径需共同评审 |
| D3 | `backend/agent/program/` 与其他模块的 bootstrap 命名不同 | 保留：CLI 入口与依赖装配不是同一职责，不机械改名 | 维持 Fleet CLI 构建和对外命令 |
| D4 | `backend/systems/` 当前只有 SQLite WorkflowJournal 适配器 | 保留明确的基础设施边界，不因只有一个组件并回工作流领域 | 不暴露存储连接或事务，也不绑定通用引擎到 SQLite |
| D5 | `backend/study/AccountWorkspace/` 已有网关、上传、发布和 Agent 控制等独立文件 | 已补 AccountWorkspace/README.md 的文件职责、账号边界、调用链与扩展导航，不机械再拆 | 保持账号隔离和既有路由，不改变鉴权 |
| D6 | 旧业务目录、AI models 目录有本地空目录；旧 CLI 仍可见 | 空目录不属于 Git 源码文件；薄转发不是重复实现，不批量删除 | 清理只能以引用证据与实际路径为准，禁止递归清理用户数据 |
| D7 | 前端已按业务模块组织，聊天根层有历史与可靠发送实现 | 先保留职责清楚的文件；性能测试与目录移动分开 | 不更改持久化、发送幂等和历史恢复行为 |

**结束标准：**所有确认需要迁移的条目都有清单、引用更新、说明与测试；保留项有理由；未通过的构建或性能门禁明确列出。新增范围先记录，不自动混入当前批次。

## 原性能计划尚需完成

1. 首屏与缓存的真实浏览器测量。当前背景元数据已引用独立 JPEG，是否还需动态导入应以现有导入图和实测为准，不能沿用旧计划中的内嵌大图体积判断。
2. 利用已完成的 gRPC 目标构建，完成主服务与 Worker 链接、TLS 就绪、失联恢复和资源隔离测试。
3. PostgreSQL 先 A/A 确定噪声，再 A/B 比较。消息持久性安全开关不降低，事务和索引只有得到证据支持才修改。
4. 推理期间普通聊天 ACK 延迟、CPU、RSS 与队列验收。
5. 权限页、控制台与网关端到端验收。Git 提交、推送、正式更新及旧版本清理分别记录和批准。

0.5B 的默认切换仍由质量门槛决定，不把“没有强行切换”算作必须补齐的代码任务。系统服务停用、数据库写入、远程代码同步和正式部署不由本清单自动授权。

## D1 本地验收（2026-11-28）

9 项实现只有已声明的路径变换，Python AST（抽象语法树）保持一致；12 个 shell 文件语法通过，模拟目标验证了任意工作目录、空格路径、空参数、环境变量与退出码转发。完整 source + Observer HTTP 回归 57 项通过。Lua 运行用例在当前 Windows 环境因缺解释器跳过，需在既有 Linux Lua 环境补验；不将跳过算通过。目录迁移未运行真实压测、数据库重建、正式服务切换或进程终止；backend/server 保持不变。
